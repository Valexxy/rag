1.Provision the Infrastructure Core:Deploy n8n, Evolution API, and Redis via Docker Compose on an Oracle Cloud VM.Start by spinning up a virtual machine instance on Oracle Cloud Infrastructure. Write a single docker-compose.yml file to deploy your three core engines:
n8n: The visual workflow orchestrator.
Evolution API: The open-source WhatsApp middleware that handles the Baileys protocol and session management.
Redis: Crucial for caching sessions and queueing outbound WhatsApp messages so you don't hit rate limits.
2.Configure Supabase:Enable pgvector and build the escrow ledger.Set up a Supabase project for your PostgreSQL database layer. You will need two core structural elements here:
Escrow Ledger Tables: To track Monnify virtual accounts, multi-party split percentages, and settlement statuses.
Vector Inventory Table: Enable the pgvector extension to store merchant product catalogs as embeddings. This is what allows your n8n agent to perform high-speed cosine similarity searches when buyers ask for items in natural language.
3.Initialize the WhatsApp Gateway:Pair the merchant device and route webhooks.Access your freshly deployed Evolution API Manager and create a new WhatsApp instance. Scan the generated QR code with the merchant's business phone to establish the connection to WhatsApp's servers.
Once paired, configure the instance to fire an HTTP POST webhook directly to your n8n production webhook URL whenever a new message.upsert (incoming chat) event occurs.
4.Build the n8n ReAct Workflow:Connect the AI agent to your database and payment gateway.Inside n8n, create the master flow that acts as the brain:
Trigger: A Webhook node catching incoming Evolution API JSON payloads.
Filter: A lightweight router to instantly drop standard personal chat patterns (so the AI doesn't reply to friends and family).
Agent Node: Connect a LangChain AI Agent (powered by OpenAI, Gemini, or Groq).
Tools: Attach custom HTTP request nodes as tools to the Agent—give it a Supabase Vector Search tool to check stock, a Monnify Virtual Account tool to generate payment links, and a Split Calculator tool to manage group math.
